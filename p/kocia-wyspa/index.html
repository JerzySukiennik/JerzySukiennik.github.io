A black capsule in the macOS menu bar that morphs between four states. Despite the name, no cats.

Not public yet

A native macOS app that puts a Dynamic Island in the menu bar of the built-in display, morphing between compact, expanded, elongated and hidden. The name is only a name — "no cats" is an explicit requirement of the specification.

Written in Swift and installed locally rather than distributed; the repository is private.
