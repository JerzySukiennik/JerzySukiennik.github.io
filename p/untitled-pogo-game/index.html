Untitled Pogo Game

Fifteen levels of pogo-stick parkour, playable together, installable as an app.

Play Untitled Pogo Game ↗

One button, one stick, fifteen levels that get mean quickly. The jump is a spring rather than a fixed arc, so timing the compression matters more than timing the press.

It runs as an installable web app and has a co-op mode, which turns the harder levels into a race where both of you are usually wrong.
