Voxel Demolition

A destruction sandbox with twenty-five tools and co-op for four. Runs on a server at home.

Not public yet Source ↗

Everything in the plaza is made of voxels and everything comes apart: hammers, charges, a shotgun and a launcher, plus builder tools that put material back. Twenty-five of them, grouped so you can cycle by category rather than hunting through a list.

Up to four people share one world through a headless Node server that holds the authoritative state. That is also why there is no link to play here yet — the server runs on a laptop at home, so for now the code is what you can look at.
