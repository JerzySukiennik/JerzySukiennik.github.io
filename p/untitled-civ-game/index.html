Untitled Civ Game

One to three gods share a single city and take down a rival built by the machine.

Not public yet Source ↗

A cooperative real-time strategy game where the players are not opponents. Everyone runs the same city, the enemy is a bot settlement growing on the other side of the map, and a match lands somewhere between twenty and forty minutes with pause available at any point.

Built in a single pass and complete, but it needs its own server process to run, so there is no public link yet — the source is here and it starts with one command.
