NAREK

A deliberately goofy 3D mascot for Narew Labs, generated by script in Blender rather than sculpted.

Not public yet

A character for the AI lab, built with an inverse-kinematics rig so it can be posed and animated. The model is produced by a script rather than modelled by hand, which means a change to the proportions is a change to a number, not an afternoon of sculpting.
